# 打得怎么样：漏斗与周对照

## 这个技能解决什么

记录有了，但没人看，或者看了只看到"总接触量"。总量没有管理意义：它同时被点位质量、人员方法、努力程度三个变量污染。

这个技能把记录切成三段，让每一段各回答一个问题。

## 输入

- 点位表、记录表（字段见 `docs/数据与边界.md`）。
- 上周的判断：哪个点位要放弃、哪句话术要改、谁需要跟。

## 三个切法

**按点位切**——回答"这个地方值不值得再去"。看两件事：去了几次、转化率。去了五次以上、转化率仍在 1% 以下，要么换时段，要么换点位。

**按人切**——回答"是方法问题还是态度问题"。看三个数：接触量、留联系率、成交率。接触量低是态度，留联系率低是开口有问题，成交率低是跟进有问题。三者对症不同。

**按周切**——回答"这周和上周比，变的是哪一段"。只比一段，不要三张表一起上。

跑法：

```bash
python3 scripts/funnel.py --points points.csv --notes notes.json
python3 scripts/funnel.py --points points.csv --notes notes.json --json   # 接你自己的看板
```

## 步骤

1. **先修数据。** 点位编号对不上、日期缺失、接触数为 0 的记录先清。数据不干净时，任何结论都是自证。
2. **只选一段看。** 本周有明确动作的（改了点位、改了话术、加了人），就看对应那一段。
3. **写一句判断，不写一段总结。** 判断必须能落到动作：哪个点位下周不去、哪句话术这周换、哪个人这周跟一趟。
4. **下周回来看这条判断对不对。** 这是唯一让复盘不流于形式的一步。

## 判据

- 判断能不能指出具体点位或具体人。指不出来的是感想，不是判断。
- 每条判断有没有对应动作和负责人。没有动作的判断下周一就会消失。
- 本周的判断，下周有没有被验证。连续三周不验证，说明没人真的在用这套数。

## 什么时候不该用

- 记录量太少（一周不到 20 条）：样本不够，任何比率都在噪声里。先攒量。
- 业务本身刚变（换产品、换区域）：与历史不可比，只看绝对数。
- 用它给人排名发奖金：这套数据的颗粒度撑不住个人考核，会立刻催生数据作假。它适合发现问题，不适合发钱。

## 一句话

漏斗不是用来证明谁行的，是用来发现哪一段断了。断点在哪，动作就在哪。
