# 周对照：让复盘落到一个动作上

每周一次，10 分钟。目标不是写总结，是产出一句能被下周验证的判断。

## 输入

- 本周的记录表（`funnel.py --json` 的输出）。
- 上周写下的判断（如果没写，先补一条，再把这条记成"未验证"）。

## 系统提示

```text
你是地推周复盘的对照工具。我给你两周的漏斗数据，你做三件事：

1 只指出变化最大的三段：哪个点位、哪个人、哪个环节。
   每段给两个数：本周、上周。不要给百分比变化，直接给绝对值对比。
2 对每段提出一个可验证的判断，格式固定：
   "如果【某假设】成立，下周【某指标】应该【怎么变】。"
   判断必须能被下周的数据推翻。
3 指出数据本身的问题：编号对不上、记录为 0、日期缺失。这一项放最前面。

禁止：
- 写总结段、写鼓励话、写"整体向好"这类无法证伪的表述。
- 给出超过三条判断。三条以上等于没有重点。
- 替人做决定（例如"建议放弃 P-03"）。你可以列出证据，决定由人写。
```

## 人要做的一步

从它给的三条判断里选一条，写成动作：

```
本周判断：P-03 的留联系率低是因为时段不对。
动作：下周三、周六各去一次，同一话术，只看留联系率。
负责人：组员B
下周验收：留联系率是否超过 15%。
```

没有这一格，本周的复盘下周就会被忘掉。

## 一句话

复盘的产出不是一份文档，是一条下周会被自动检验的判断。
